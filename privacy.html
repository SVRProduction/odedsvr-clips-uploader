Privacy Policy: OdedSVR Clips Uploader

Effective date: November 5, 2026

Who uses this tool

OdedSVR Clips Uploader ("the tool") is an internal desktop script run on one personal computer by the owner of the YouTube channel OdedSVR Clips (channel ID UCetsSw4eEYwK4DsHhKAVoXw). It has no public sign-up and no other users.

YouTube API Services

The tool uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • An OAuth 2.0 token for the owner's own Google account, with the scopes youtube.upload and youtube.
  • The ID and title of the signed-in channel (channels.list, mine=true), used only to confirm that the token belongs to OdedSVR Clips before uploading.
  • The IDs of the videos it uploads (returned by videos.insert), used to set their thumbnails (thumbnails.set).

The tool does not read, collect, or store data about any other user or channel, comments, viewers, or analytics.

How the data is used, stored, and shared

  • The OAuth token is stored only on the owner's computer, in a file readable only by the owner. It is never sent anywhere except to Google's own APIs.
  • Uploaded video IDs are kept in a local log on the same computer to avoid uploading a video twice.
  • No data is sold, shared with third parties, or used for advertising.
  • The tool does not use cookies or tracking technologies of any kind.

Deletion and revoking access

The owner can delete the stored token and local logs at any time by deleting the files from his computer. Access can also be revoked at any time on the Google security settings page. After revocation, the tool can no longer access the account, and any stored token becomes useless. Any stored YouTube API data is deleted or refreshed within 30 days, as the YouTube API Services Developer Policies require.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
